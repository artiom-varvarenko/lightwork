# Lightwork

Any procedure, on the real thing, verified.

Lightwork turns a written procedure into light on the real objects, watches each step through a camera, and only
advances once Meta's models and a deterministic evidence gate agree the step was done right.

Entry for the Meta Global AI Developer Hackathon (Indie Developer track, "Push the Frontier"). Work in progress;
setup, live mode and judge replay mode will be documented here.
